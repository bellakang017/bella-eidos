# bella eidos

Personal constructivist learning tool for ADHD learners.

Built on the C-N-A framework:
- **Constructivism** (Piaget + Vygotsky) — active knowledge construction
- **Neuroscience** (Huberman) — 90min focus sessions, micro-rest, error-driven neuroplasticity
- **AI Pedagogy** (Andrew Ng) — modular, hands-on, scaffolded

## B+ Core Features

- 90-minute ultradian timer
- Random micro-rest intervals (10s every 90-180s)
- Error reframing as neuroplasticity signal
- Session tracking with streak system

## Domains

- MD & YAML Trainer (flashcards, sandbox, challenges, glossary)
- More coming soon

## Deploy

Static HTML/CSS/JS. No build system. Publish via GitHub Pages.
