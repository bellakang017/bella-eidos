Challenge
직접 타이핑해서 제출. 정답과 비교해볼 수 있어.
Glossary
대부분 일상 사물에서 왔어. 원래 뜻을 알면 컴퓨터 뜻이 자동으로 추론돼.
건축/건설에서 온 용어
건물을 짓는 것처럼 소프트웨어를 "짓는다"
Framework
건물 뼈대 (철골) → 코드의 기본 구조. 뼈대가 있고 살만 붙이면 됨.
Stack
접시 쌓기 → 기술을 층층이 쌓은 것. "tech stack" = 프로젝트에 쓴 기술 층.
Architecture
건축 설계 → 시스템 전체 구조 설계.
Scaffolding
공사장 비계 → 초기 뼈대 코드 자동 생성. 완성 후 걷어냄.
Build
건물 짓기 → 코드를 실행 가능한 프로그램으로 조립.
Deploy
군대 배치 → 완성된 프로그램을 실제 서버에 올리기.
물/배관에서 온 용어
데이터가 물처럼 "흐른다"
Pipeline
수도관/송유관 → 데이터가 단계별로 흘러가는 처리 과정. A → B → C.
Stream
시냇물 → 데이터가 끊김 없이 연속으로 흘러옴.
Port
항구 → 컴퓨터의 출입구. 데이터가 드나드는 문.
Socket
전기 콘센트 → 두 프로그램이 연결되는 접점.
Flush
물 내리기 → 임시 저장된 데이터를 한꺼번에 내보내기.
물건/공간에서 온 용어
보이지 않는 것을 보이는 물건에 비유
Container
화물 컨테이너 → 프로그램을 상자에 넣어서 어디서든 동일하게 실행.
Sandbox
모래놀이터 → 안전한 실험 공간. 진짜 시스템에 영향 없음.
Repository
저장소/창고 → 코드를 보관하는 곳 (GitHub 등).
Library
도서관 → 미리 만들어진 코드 모음. 필요할 때 빌려 쓰기.
Cache
숨겨둔 보급품 (프랑스어 cacher=숨기다) → 자주 쓰는 데이터를 가까이 숨겨두고 빠르게 꺼냄.
Bucket
양동이 → 데이터를 담는 큰 통 (클라우드 저장소).
Token
동전/토큰 → 데이터의 최소 단위. LLM에서 단어 쪼개진 조각.
사람/행동에서 온 용어
사람이 하는 행동으로 컴퓨터 작업을 설명
Bug
벌레 → 코드 오류. 1947년 진짜 나방이 컴퓨터에 끼어서 고장, 여기서 유래.
Debugging
벌레 잡기 → 오류 찾아서 고치기.
Daemon
수호신 (그리스 신화) → 백그라운드에서 조용히 돌아가는 프로그램.
Fork
포크 (갈림길) → 프로젝트를 복사해서 다른 방향으로 개발.
Clone
복제 → 저장소를 그대로 복사해서 내 컴퓨터에.
Push / Pull
밀다 / 당기다 → 코드를 서버에 올리기 / 서버에서 가져오기.
Merge
합치다 → 두 갈래 코드를 하나로.
온톨로지/데이터 용어
Bella가 강의에서 배운 것
Ontology
존재론 (철학: "뭐가 존재하는가?") → 데이터 세계의 존재 규칙. 뭐가 있고 어떻게 연결되는가.
Schema
형태/구조 (그리스어) → 데이터의 구조 정의서.
Graph
그래프 (점+선) → 노드(점)와 엣지(선)로 관계를 표현.
Node
매듭 → 그래프의 한 점 (하나의 데이터).
Edge
가장자리/연결선 → 노드 사이의 관계.
Query
질문 (라틴어 quaerere) → 데이터에 던지는 질문.
Index
책 색인 → 데이터를 빨리 찾기 위한 목차.
Embedding
끼워 넣기 → 데이터를 숫자 공간에 끼워 넣어 위치 부여.
Hallucination
환각 → LLM이 실제로 없는 정보를 있다고 생성하는 현상.
Grounding
접지 (땅에 닿게 하기) → LLM 출력을 실제 데이터에 대조해서 검증.
패턴 인식 팁: 새로운 기술 용어를 만나면 "이 단어의 일상적 뜻이 뭐지?" 물어봐. 그러면 컴퓨터에서의 역할이 거의 자동으로 추론돼.

예: "Docker" = 부두 노동자(docker). 컨테이너를 싣고 내리는 사람 → 컨테이너를 관리하는 도구.
