Glossary
Most terms come from everyday objects. Know the origin, infer the meaning.
Terms from Architecture
한국어건물을 짓는 것처럼 소프트웨어를 "짓는다"
Framework
Building skeleton (steel frame) → The foundational structure of code. The skeleton is there; you just add the flesh.
한국어건물 뼈대 (철골) → 코드의 기본 구조. 뼈대가 있고 살만 붙이면 됨.
Stack
Stacking plates → Technologies layered on top of each other. "Tech stack" = the layers of tech in a project.
한국어접시 쌓기 → 기술을 층층이 쌓은 것. "tech stack" = 프로젝트에 쓴 기술 층.
Architecture
Architectural design → The overall structural design of a system.
한국어건축 설계 → 시스템 전체 구조 설계.
Scaffolding
Construction scaffolding → Auto-generated starter code. Removed after completion.
한국어공사장 비계 → 초기 뼈대 코드 자동 생성. 완성 후 걷어냄.
Build
Constructing a building → Assembling code into a runnable program.
한국어건물 짓기 → 코드를 실행 가능한 프로그램으로 조립.
Deploy
Military deployment → Putting a finished program onto a live server.
한국어군대 배치 → 완성된 프로그램을 실제 서버에 올리기.
Terms from Plumbing
한국어데이터가 물처럼 "흐른다"
Pipeline
Water pipe / oil pipeline → A multi-step process where data flows through stages. A → B → C.
한국어수도관/송유관 → 데이터가 단계별로 흘러가는 처리 과정. A → B → C.
Stream
A brook → Data flowing in continuously without interruption.
한국어시냇물 → 데이터가 끊김 없이 연속으로 흘러옴.
Port
Harbor → A gateway on a computer. The door through which data enters and exits.
한국어항구 → 컴퓨터의 출입구. 데이터가 드나드는 문.
Socket
Electrical outlet → The connection point where two programs meet.
한국어전기 콘센트 → 두 프로그램이 연결되는 접점.
Flush
Flushing water → Pushing all temporarily stored data out at once.
한국어물 내리기 → 임시 저장된 데이터를 한꺼번에 내보내기.
Terms from Objects & Spaces
한국어보이지 않는 것을 보이는 물건에 비유
Container
Shipping container → Packaging a program in a box so it runs identically anywhere.
한국어화물 컨테이너 → 프로그램을 상자에 넣어서 어디서든 동일하게 실행.
Sandbox
Sandbox (playground) → A safe space for experiments. No impact on the real system.
한국어모래놀이터 → 안전한 실험 공간. 진짜 시스템에 영향 없음.
Repository
Storage / warehouse → A place to store code (e.g. GitHub).
한국어저장소/창고 → 코드를 보관하는 곳 (GitHub 등).
Library
Library → A pre-made collection of code. Borrow what you need.
한국어도서관 → 미리 만들어진 코드 모음. 필요할 때 빌려 쓰기.
Cache
Hidden supply stash (French cacher = to hide) → Keeping frequently used data close by for fast retrieval.
한국어숨겨둔 보급품 (프랑스어 cacher=숨기다) → 자주 쓰는 데이터를 가까이 숨겨두고 빠르게 꺼냄.
Bucket
Bucket → A large container for data (cloud storage).
한국어양동이 → 데이터를 담는 큰 통 (클라우드 저장소).
Token
Coin / token → The smallest unit of data. In LLMs, a broken-up piece of a word.
한국어동전/토큰 → 데이터의 최소 단위. LLM에서 단어 쪼개진 조각.
Terms from Human Actions
한국어사람이 하는 행동으로 컴퓨터 작업을 설명
Bug
Insect → A code error. In 1947, a real moth got stuck in a computer and caused a malfunction — hence the name.
한국어벌레 → 코드 오류. 1947년 진짜 나방이 컴퓨터에 끼어서 고장, 여기서 유래.
Debugging
Bug catching → Finding and fixing errors.
한국어벌레 잡기 → 오류 찾아서 고치기.
Daemon
Guardian spirit (Greek mythology) → A program running quietly in the background.
한국어수호신 (그리스 신화) → 백그라운드에서 조용히 돌아가는 프로그램.
Fork
Fork (a fork in the road) → Copying a project and developing it in a different direction.
한국어포크 (갈림길) → 프로젝트를 복사해서 다른 방향으로 개발.
Clone
Clone → Copying a repository exactly to your own computer.
한국어복제 → 저장소를 그대로 복사해서 내 컴퓨터에.
Push / Pull
Push / Pull → Uploading code to a server / downloading code from a server.
한국어밀다 / 당기다 → 코드를 서버에 올리기 / 서버에서 가져오기.
Merge
Merge → Combining two branches of code into one.
한국어합치다 → 두 갈래 코드를 하나로.
Ontology & Data Terms
Terms from Bella's coursework
Ontology
Ontology (philosophy: "what exists?") → The rules of existence in a data world. What exists and how it connects.
한국어존재론 (철학: "뭐가 존재하는가?") → 데이터 세계의 존재 규칙. 뭐가 있고 어떻게 연결되는가.
Schema
Form / structure (Greek) → A definition document for data structure.
한국어형태/구조 (그리스어) → 데이터의 구조 정의서.
Graph
Graph (dots + lines) → Representing relationships with nodes (dots) and edges (lines).
한국어그래프 (점+선) → 노드(점)와 엣지(선)로 관계를 표현.
Node
Knot → A single point in a graph (one piece of data).
한국어매듭 → 그래프의 한 점 (하나의 데이터).
Edge
Edge / connecting line → The relationship between nodes.
한국어가장자리/연결선 → 노드 사이의 관계.
Query
Question (Latin quaerere) → A question posed to data.
한국어질문 (라틴어 quaerere) → 데이터에 던지는 질문.
Index
Book index → A table of contents for finding data quickly.
한국어책 색인 → 데이터를 빨리 찾기 위한 목차.
Embedding
Embedding (fitting in) → Placing data into a numerical space to assign position.
한국어끼워 넣기 → 데이터를 숫자 공간에 끼워 넣어 위치 부여.
Hallucination
Hallucination → When an LLM generates information that doesn't actually exist.
한국어환각 → LLM이 실제로 없는 정보를 있다고 생성하는 현상.
Grounding
Grounding (connecting to earth) → Verifying LLM output by cross-checking against real data.
한국어접지 (땅에 닿게 하기) → LLM 출력을 실제 데이터에 대조해서 검증.
Pattern recognition tip: When you encounter a new technical term, ask "What does this word mean in everyday life?" Then the role it plays in computing almost automatically becomes clear.

Example: "Docker" = a dockworker. Someone who loads and unloads containers → a tool that manages containers.
한국어새로운 기술 용어를 만나면 "이 단어의 일상적 뜻이 뭐지?" 물어봐. 그러면 컴퓨터에서의 역할이 거의 자동으로 추론돼. 예: "Docker" = 부두 노동자(docker). 컨테이너를 싣고 내리는 사람 → 컨테이너를 관리하는 도구.

How to Read Shortcuts:
When you see a key combination, interpret it like this:
• Cmd = "Do this" (base command)
• + Shift = "Extended / opposite version"
• + Option = "Modified version"
• Last letter = the action (S=Save, F=Find, K=linK, E=Edit, O=Open, P=Palette)
한국어조합을 볼 때 이렇게 해석해: Cmd = "이걸 해" (기본 명령), + Shift = "확장/반대 버전으로", + Option = "변형 버전으로", 마지막 글자 = 행동 (S=Save, F=Find, K=linK, E=Edit, O=Open, P=Palette)

⌥ Opt
"But do it differently" — the modifier key
⇧ Shift
"Do the opposite / extended version" — the extension key
⌃ Ctrl
Secondary command key (supporting role on Mac)
Fn
"Use this key's hidden function" — toggles F-keys
